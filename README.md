# password-checker
My name is Rohit Yadav  and I am a BCA (Bachelor of Computer Applications) student . This project, Password Strength Checker, is developed as part of my academic learning to understand web application development and password validation.

Project Overview
Password Strength Checker is a simple web-based application developed using HTML, CSS,  and PHP.
The purpose of this project is to check the strength of a password based on different security requirements. The application evaluates the password and displays whether it is Weak, Medium, or Strong.
It also provides suggestions to help the user create a more secure password.

Technologies Used
HTML5	:Creating the webpage structure and form
CSS3:Designing and styling the interface
PHP: Server-side password strength evaluation

Password Requirements
The application checks the following five conditions:
1.	Password must contain at least 8 characters. 
2.	Password must contain an uppercase letter (A-Z). 
3.	Password must contain a lowercase letter (a-z). 
4.	Password must contain a number (0-9). 
5.	Password must contain a special character, such as:
! @ # $ % ^ & * 

Features
1. Password Input
The user can enter a password into the password field.
2. Strength Indicator
A progress bar displays the strength of the password.
•	Red → Weak 
•	Orange → Medium 
•	Green → Strong 
4. Password Requirements
The application displays all password requirements and marks completed requirements with a check mark.
5. Server-Side Validation
PHP checks the password when the user clicks the Check Password button.
6. Improvement Suggestions
The application provides useful tips for creating a stronger password.

How to Run the Project
Step 1: Install XAMPP
Install XAMPP on your computer.
Step 2: Open htdocs
Go to:
C:\xampp\htdocs\
Step 3: Copy Project
Copy the complete project folder into htdocs.
The folder should look like:
C:\xampp\htdocs\pass \
Step 4: Start Apache
Open XAMPP Control Panel and start:
Apache
No MySQL database is required for this project.
Step 5: Open Browser
Open your browser and enter:
http://localhost/password/
The Password Strength Checker will open.
